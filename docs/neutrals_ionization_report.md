# Нейтральные атомы и ионизация в hetsim: отчёт

Модель переноса нейтрального газа и его ионизации для осесимметричного
(r, z) расчёта холловского двигателя (класс СПД-70). Отчёт описывает **что**
сделано, **как** это реализовано численно и **почему** выбраны именно такие
формулировки.

Добавленные / изменённые файлы:

| Файл | Содержание |
|------|-----------|
| `src/physics/ionization.py` | сечения ионизации, коэффициент скорости `k_iz(T_e)`, частота и объёмная скорость ионизации |
| `src/physics/neutrals.py` | дивергенция потока, явный шаг неразрывности, стационарный конечно-объёмный решатель неразрывности |
| `src/examples/neutral_flow/spt70_neutral_flow.py` | сквозной пример: депозиция → ионизация → неразрывность |
| `src/examples/neutral_flow/spt70_neutral_flow.png` | результат примера (6 панелей) |

---

## 1. Постановка задачи

Уже была реализована **депозиция** макрочастиц на сетку (`deposit`): частицы
рассеиваются по 4 узлам с билинейными весами, и после нормировки на осесимметричный
контрольный объём получаются поля плотности `n`, скоростей `v_r`, `v_z` и
температуры `T`. Требовалось:

1. **Найти распределение нейтральных атомов** из уравнения неразрывности.
2. **Учесть ионизацию** — желательно через сечения столкновений, чтобы модель можно
   было связать с температурой электронов `T_e` и получать более точные данные.

Ключевое физическое требование холловского двигателя: нейтралы (обычно ксенон)
подаются с анода, движутся вдоль оси и **выедаются ионизацией** в прианодно-выходном
слое, где электроны горячие. Именно это и должна воспроизводить модель.

## 2. Физическая модель

### 2.1 Уравнение неразрывности нейтралов

Закон сохранения числа нейтральных атомов:

```
∂n/∂t + ∇·(n u) = -S_iz + q,
```

где `n` — концентрация нейтралов [м⁻³], `u = (v_r, v_z)` — их средняя скорость,
`S_iz` — объёмная скорость ионизации (сток нейтралов) [м⁻³с⁻¹], `q` — сторонний
источник (обычно 0).

В осесимметричных цилиндрических координатах (без азимутальной зависимости)
дивергенция потока `F = n u`:

```
∇·F = (1/r) ∂(r n v_r)/∂r + ∂(n v_z)/∂z.
```

На оси `r = 0` особенность `(1/r)∂(r F_r)/∂r` устраняется предельным переходом:
поскольку `F_r ~ r` при `r → 0`, имеем `lim = 2 ∂F_r/∂r`.

**Стационарная** форма (когда нас интересует установившееся распределение при
заданном поле скоростей и стоке):

```
∇·(n u) + ν n = q.
```

Здесь сток записан как **линейный** по `n`: `S_iz = ν n`, где `ν` — частота
ионизации [с⁻¹] (см. §2.3). Линейность по `n` принципиальна — благодаря ей
стационарная задача сводится к **одному** решению линейной системы, без итераций
по времени.

### 2.2 Ионизация через сечение столкновений

Скорость ионизации электронным ударом на один нейтрал и один электрон задаётся
**коэффициентом скорости реакции** (rate coefficient):

```
k_iz(T_e) = ⟨σ_iz(v) v⟩,
```

усреднённым по функции распределения электронов по скоростям. Для изотропного
максвелловского распределения с температурой `T_e` (в эВ) усреднение по энергии
даёт:

```
                     ⌠∞
k_iz = C · T_e^(-3/2) │  σ(E) · E · exp(-E/T_e) dE,      C = (2/√π)·√(2e/mₑ).
                     ⌡E_iz
```

**Вывод.** По определению `k = ∫ σ(E) v(E) f(E) dE`, где для 3D-максвелловца
доля электронов с энергией в `[E, E+dE]`

```
f(E) dE = (2/√π) · T_e^(-3/2) · √E · exp(-E/T_e) dE,   v(E) = √(2eE/mₑ).
```

Подстановка и вынос констант дают формулу выше; множитель `e` (заряд электрона,
Дж/эВ) переводит энергию из эВ в Дж внутри `v(E)`. Проверка размерности: `[C] =
(м/с)·эВ^(-1/2)`, интеграл `[σ E dE] = м²·эВ²`, вместе с `T_e^(-3/2)` получается
`м³/с` — как и должно быть.

Нижний предел `E_iz` — порог ионизации (для Xe `E_iz = 12.13 эВ`); ниже порога
`σ = 0`.

**Сечение `σ(E)`.** По умолчанию используется одноуровневая формула Лотца
(Lotz), физически мотивированная и компактная:

```
σ(E) = a · q · ln(E/E_iz) / (E · E_iz),   E ≥ E_iz,
```

где `q` — число эквивалентных электронов внешней оболочки (для Xe 5p⁶: `q = 6`),
`a = 4.5·10⁻¹⁸ м²·эВ²`. Для количественных расчётов предусмотрена подстановка
**измеренного** сечения через табличную интерполяцию (`tabulated_cross_section`)
— остальной конвейер при этом не меняется.

### 2.3 Связь с плазмой

- **Частота ионизации** (потеря на один нейтрал):
  `ν = n_e · k_iz(T_e)` [с⁻¹].
- **Объёмная скорость ионизации** (сток нейтралов = источник ионов/электронов):
  `S_iz = n_n · n_e · k_iz(T_e) = ν · n_n` [м⁻³с⁻¹].

`ν` — это именно тот вход, который потребляет стационарный решатель неразрывности;
`S_iz` — естественная «передача» в плазменную/электронную модель.

## 3. Численные схемы

### 3.1 Контрольные объёмы (согласование с `deposit`)

Все схемы используют **тот же** осесимметричный контрольный объём, что и `deposit`,
— это гарантирует согласованность плотности, полученной депозицией, и плотности из
неразрывности. Для узла `i` по радиусу берётся кольцо

```
ring[i] = π (r_hi² - r_lo²),   r_lo = max(r_i - h_r/2, r_min),  r_hi = min(r_i + h_r/2, r_max),
```

которое остаётся конечным на оси (в отличие от «голого» `2π r_i dr`). Осевой размер
ячейки `dz[j] = h_z` внутри и `h_z/2` на торцах. Объём `vol[i,j] = ring[i]·dz[j]`.
Эта геометрия вынесена в приватный помощник `_cell_geometry`.

### 3.2 Стационарный решатель: конечные объёмы + противопоток (upwind)

`solve_neutral_continuity` решает `∇·(n u) + ν n = q` методом конечных объёмов
первого порядка с **противопоточной** аппроксимацией плотности на гранях.

Для каждой ячейки суммируется поток через 4 грани:

```
Σ_грани (площадь · u_норм · n_upwind) + ν_P vol_P n_P = q_P vol_P.
```

- Скорость на грани — среднее двух соседних узлов (`0.5(u_P + u_neighbor)`); на
  граничной грани берётся односторонне (`u_P`).
- **Противопоток:** если поток через грань направлен *наружу* (`u_норм > 0`),
  «донором» является сама ячейка `P` (вклад в диагональ); если *внутрь*
  (`u_норм < 0`) — сосед (внедиагональный элемент). Это стандартный устойчивый
  выбор для адвекции: он не даёт осцилляций, ценой численной диффузии (см. §6).
- Площади граней: осевые грани — `ring[i]`; радиальные — `2π r_face · dz[j]` с
  `r_face = r_lo` (нижняя) и `r_hi` (верхняя). На оси `r_lo = 0`, поэтому нижняя
  грань имеет нулевую площадь и автоматически выпадает (условие симметрии).

### 3.3 Граничные условия

- **Вход (анод):** узлы маски `inlet_mask` фиксируются на `inlet_density`
  (Дирихле) — строка матрицы становится единичной.
- **Прочие границы — пассивный «открытый» выход:** через граничную грань нейтралы
  могут только *вытекать* (там, где поток направлен наружу — вклад в диагональ);
  *втекания* извне нет. Одно и то же правило корректно описывает и твёрдые стенки
  (там поток касательный, `u_норм ≈ 0`), и ось (нулевая площадь грани), и осевой
  выход из области.

> **Важно про устойчивость матрицы.** Если у ячейки нет ни одной вытекающей грани и
> `ν = 0`, диагональ обнуляется и матрица вырождается. На практике это случается в
> ячейках с нулевой скоростью (например, куда депозиция не занесла частиц). В примере
> это обходится подстановкой средней дрейфовой скорости в такие ячейки (§5), так что
> транспорт остаётся определён везде.

### 3.4 Разреженный решатель

Система собирается в COO-формате (`rows/cols/data`) и решается прямым разреженным
методом `scipy.sparse.linalg.spsolve` — тот же приём, что в `magnetic.py`
(`solve_axisymmetric_flux`). Матрица размера `(N_r·N_z)²`, разреженная (≤5
ненулевых на строку).

### 3.5 Явный шаг по времени

`advance_neutral_density` — явный шаг Эйлера для нестационарной связки с частичным
пушем: `n^{new} = n - dt(∇·(n u) + S)`, с обрезкой снизу нулём. Условие
устойчивости CFL: `dt < min(h_r, h_z)/max|u|`.

### 3.6 Дивергенция потока (диагностика)

`neutral_flux_divergence` вычисляет `∇·(n u)` через `np.gradient` с корректной
обработкой оси (`2 ∂F_r/∂r` при `r=0`). Используется как проверка сохранения массы:
в бессточной области должна обращаться в ~0.

### 3.7 Интегрирование максвелловского усреднения

`maxwellian_rate_coefficient` вычисляет интеграл §2.2 **векторизованно** по всему
полю `T_e`:

- энергетическая сетка `E ∈ [E_iz, E_iz + energy_span·max(T_e)]` (по умолчанию
  `energy_span = 30`, т.к. максвелловский хвост далеко за `T_e` пренебрежимо мал);
- сечение `σ(E)` считается один раз на этой сетке;
- подынтегральное выражение `σ(E)·E·exp(-E/T_e)` собирается броадкастингом по всем
  ячейкам и интегрируется трапециями (`np.trapezoid`, 512 узлов);
- ячейки с `T_e ≤ 0` дают `k_iz = 0`.

Скаляр на входе → скаляр на выходе; поле `T_e` формы `(N_r, N_z)` → поле `k_iz` той
же формы.

## 4. API реализованных функций

**`ionization.py`**

| Функция | Назначение |
|---------|-----------|
| `lotz_cross_section(E, ...)` | сечение Лотца σ(E) [м²] (умолчание — Xe) |
| `tabulated_cross_section(E_tab, σ_tab)` | построить σ(E) из измеренных данных (лин. интерполяция) |
| `maxwellian_rate_coefficient(T_e, cross_section=...)` | `k_iz(T_e)` [м³/с] — максвелловское усреднение |
| `ionization_frequency(n_e, T_e, ...)` | `ν = n_e k_iz` [с⁻¹] — вход стационарного решателя |
| `ionization_rate(n_n, n_e, T_e, ...)` | `S_iz = n_n n_e k_iz` [м⁻³с⁻¹] — сток/источник |

**`neutrals.py`** (в дополнение к `deposit`)

| Функция | Назначение |
|---------|-----------|
| `neutral_flux_divergence(grid, n, v_r, v_z)` | `∇·(n u)` — диагностика сохранения массы |
| `advance_neutral_density(grid, n, v_r, v_z, dt, sink=None)` | явный шаг неразрывности со стоком |
| `solve_neutral_continuity(grid, v_r, v_z, inlet_mask, inlet_density, ionization_freq=None, source=None)` | **стационарное распределение нейтралов** с учётом ионизации |

**Как всё связано:**
`deposit → (n, v_r, v_z, T)`; скорости идут в `solve_neutral_continuity`, а
`ionization_frequency(n_e, T_e)` — как сток; на выходе — плотность нейтралов,
выеденная ионизацией. `ionization_rate` даёт согласованный источник ионов/электронов
для плазменной части.

## 5. Пример: `spt70_neutral_flow.py`

### 5.1 Постановка

Иллюстративный СПД-70 (геометрия согласована с магнитным примером): канал
`R_in = 21 мм`, `R_out = 35 мм`, анод `z = 20 мм`, срез `z = 45 мм`. Рабочая точка:
расход `2.5 мг/с` Xe, температура газа `700 К`, дрейф `150 м/с`.

Шаги примера:

1. **Депозиция.** 40000 макрочастиц заполняют кольцо канала со сдвинутым
   максвелловским распределением скоростей (осевой дрейф + тепловой разброс
   `√(kT/m) ≈ 210 м/с`). Вес частицы подобран так, чтобы равномерное заполнение
   давало целевую входную концентрацию. Депозиция → поля `n, v_r, v_z`; шумы Монте-
   Карло гасятся сглаживанием (`smoothing`).
2. **Ионизация.** Заданы представительные профили `T_e(z)` (гауссов горб до 22 эВ у
   среза) и `n_e(z)` (пик `3·10¹⁷ м⁻³`), радиально ограниченные каналом — они играют
   роль будущей электронной модели. По сечениям считается `k_iz(T_e)` и `ν = n_e k_iz`.
3. **Неразрывность.** Стационарный решатель с полем скоростей от депозиции (в
   «пустых» ячейках скорость заменяется дрейфом, а само поле скорости сглаживается —
   иначе шум скорости вызывает нефизичное накопление массы) и стоком `ν` даёт
   выеденную ионизацией плотность. Для контраста решается и вариант **без** ионизации.

### 5.2 Результаты

Печать примера:

```
channel area           : 24.63 cm^2
inlet neutral density  : 3.104e+19 m^-3
neutral thermal speed  : 210.5 m/s (drift 150 m/s)
deposited density (mid): 3.062e+19 m^-3 (target 3.104e+19)   ← депозиция ≈ цель
k_iz at T_e=22 eV      : 1.593e-13 m^3/s
max ionization freq    : 4.736e+04 1/s (mean free time 21.12 us)
injected neutral flux  : 1.147e+19 atoms/s
total ionization rate  : 1.080e+19 atoms/s
propellant utilization : 94.2 %
neutral depletion at exit: n_exit/n_in = 0.14 at mid-radius
```

Физическая картина (рис. `spt70_neutral_flow.png`, 6 панелей):

- **Депонированная плотность** ≈ однородна по каналу (~3·10¹⁹ м⁻³) — «холодный газ»
  без ионизации.
- **T_e и n_e** — горбы у среза (прианодно-выходной ионизационный слой).
- **Плотность из неразрывности с ионизацией** — резко падает поперёк слоя ионизации,
  до ~14 % от входной у среза.
- **Скорость ионизации `S_iz`** — локализована там, где одновременно велики
  `n_n`, `n_e` и `T_e`.
- **Осевые профили** наглядно показывают выедание нейтралов синхронно с ростом `T_e`.

Значения физически осмысленны: `k_iz ~ 10⁻¹³ м³/с` для Xe при 20+ эВ,
использование топлива ~94 % — типично для хорошо настроенного холловского двигателя.

## 6. Верификация

| Проверка | Результат |
|----------|-----------|
| `k_iz(T_e)` для Xe при 1…40 эВ | `4·10⁻¹⁹ … 2·10⁻¹³ м³/с` — верный порядок и порог |
| Чистая адвекция (без ионизации, `v_z=const`) | `n_out/n_in = 1.0` — масса сохраняется точно |
| Адвекция + постоянная `ν` | численный профиль ≈ аналитический `exp(-ν z/v_z)` (ошибка ~6 % в середине, ~16 % у выхода на сетке 40 точек — это ожидаемая численная диффузия схемы 1-го порядка, убывает при измельчении) |
| `∇·(n u)` для бездивергентного поля | ~уровень машинной точности |
| Баланс массы в примере | инжекция `1.147·10¹⁹` ≈ ионизация `1.080·10¹⁹` + вынос (94.2 %) |
| Депозиция vs цель | `3.06·10¹⁹` vs `3.10·10¹⁹ м⁻³` |

## 7. Ограничения и развитие

- **Схема 1-го порядка (upwind):** устойчива, но численно диффузионна. Резкий фронт
  ионизации размывается на грубой сетке — измельчайте `z` или переходите на схему
  2-го порядка (MUSCL/TVD), если нужна резкость фронта.
- **Сечение по умолчанию — Лотц (одноуровневый):** даёт верный порядок, но для
  количественных задач подставляйте измеренное сечение через
  `tabulated_cross_section`.
- **`T_e`, `n_e` заданы аналитически** — это заглушка электронной модели. Реальная
  точность появится при самосогласованном решении с электронами/ионами: `S_iz`
  из `ionization_rate` — готовый источник для них, а `T_e` замыкает `k_iz`.
- **Поле скоростей от депозиции шумно** — в примере оно сглаживается; в
  самосогласованном коде лучше получать `u` из моментов с достаточной статистикой или
  из отдельного уравнения импульса нейтралов.
- **Связка по времени:** для нестационарного PIC-fluid используйте
  `advance_neutral_density` со стоком `ionization_rate` вместо стационарного решателя.
