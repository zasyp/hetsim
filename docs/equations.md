# Справочник: все уравнения модели и их функции

Плоский указатель — каждое уравнение модели в одном месте, с прямой ссылкой на
функцию, которая его считает. Разборы «почему так» уже есть в `lecture.md`
(FEM-магнитостатика, блоки 4–6 электронной жидкости), `hybrid.md` (ионы,
гибридный цикл) и `mesh_convergence.md` (сходимость сетки) — здесь их не
повторяю, только компактная формула + ссылка на код + минимальный контекст.
Читайте эти три файла, если нужно «почему», а не «что».

Соглашение по единицам, общее для всего проекта: **СИ везде, кроме `T_e` и
всех потенциалов** (φ, φ*, φ_s) — они в эВ / вольтах, то есть численно
`k_B T / e`. Формат ссылки на код: `файл.py:строка` — строки актуальны на
момент написания, при рефакторинге могут съехать на несколько штук.

## 0. Магнитостатика

Осесимметричная задача, единственная компонента векторного потенциала —
азимутальная `A_φ`. Вводится функция потока `ψ = r A_φ`:

$$B_r = -\frac{1}{r}\frac{\partial \psi}{\partial z}, \qquad
B_z = \frac{1}{r}\frac{\partial \psi}{\partial r}.$$

Линии уровня `ψ` — силовые линии поля; это же `ψ` потом становится λ для
блока 3. Закон Ампера `∇×(B/μ) = J` превращается в скалярное эллиптическое
уравнение

$$\frac{\partial}{\partial r}\!\left[\frac{1}{\mu r}\frac{\partial \psi}{\partial r}\right]
+ \frac{\partial}{\partial z}\!\left[\frac{1}{\mu r}\frac{\partial \psi}{\partial z}\right]
= -J_\varphi, \qquad \mu = \mu_0\mu_r. \tag{0.1}$$

Два независимых решателя этого уравнения существуют в коде: конечно-разностный
(легаси, `method="fd"`) и конечно-элементный (по умолчанию, `method="fem"`).
Переключатель — `field_on_grid` в `magnetics/spt70_system.py:137`. Полный вывод
слабой формы, P1-элементов, ZZ-оценки ошибки и AMR — в `lecture.md`, часть I;
здесь только формулы и функции.

**Конечно-разностный путь** (`magnetics/magnetic.py`):

- `solve_axisymmetric_flux` (`magnetic.py:15`) — (0.1) пятиточечным шаблоном,
  усреднение `μ` арифметическое на гранях.
- `field_from_flux` (`magnetic.py:127`) — `B_r, B_z` из `ψ` центральной
  разностью; при переданной маске `iron` использует `_interface_gradient`
  (`magnetic.py:93`), одностороннюю разность на границе железа (лечит
  утечку поля через границу материала, см. `lecture.md` §1).
- `magnetic_streamfunction` (`magnetic.py:162`) — восстанавливает λ обратным
  интегрированием `B`: `λ(z0) = ∫r B_z dr`, затем `λ(z,r) = λ(z0,r) − ∫r B_r dz`
  (`cumulative_trapezoid`). Дифференцирование `ψ→B`, затем обратное
  интегрирование `B→λ` — источник накопленной ошибки, устранённый в FEM-пути.
- `lambda_gradient` (`magnetic.py:178`) — `∇λ = r B_z r̂ − r B_r ẑ`, напрямую из
  `B`, без численного дифференцирования λ.

**Конечно-элементный путь** (`magnetics/fem.py`, узловые P1, слабая форма
$\int(1/\mu r)\nabla\psi\cdot\nabla w\,dr\,dz = \int J_\varphi w\,dr\,dz$):

- `triangulate_structured` (`fem.py:32`) — структурная сетка → конформная
  триангуляция (2 треугольника на ячейку).
- `_p1_geometry` (`fem.py:62`) — геометрия элемента: площадь `A`, постоянный на
  элементе градиент `∇φ_i = (b_i,c_i)/2A`, центроид `r_c`.
- `assemble` (`fem.py:84`) — локальная матрица жёсткости
  `K^e_{ij} = (1/(μ r_c))(∇φ_i·∇φ_j) A^e`, вектор нагрузки `f^e_i = J_φ A^e/3`,
  сборка в `csr_matrix`, граничные условия Дирихле `ψ=0` на оси и внешней
  границе.
- `recover_B_elements` (`fem.py:122`) — `B` поэлементно (`B_r=-∂ψ/∂z / r`,
  `B_z=∂ψ/∂r / r`), честно двузначно на границе материалов.
- `recover_B_nodal` (`fem.py:136`) — узловое сглаживание, раздельно по
  материалам (только вакуумные элементы), взвешено объёмом `A·r_c`.
- `zz_error` (`fem.py:294`) — оценка ошибки Зенкевича–Чжу
  `η_e ≈ |B*_e − B_{h,e}|·√A_e` (`B*` — сглаженное поле, `B_h` — сырое).
- `mark_for_refinement` (`fem.py:317`) — правило отбора: верхние `amr_frac`
  элементов внутри ROI (вакуум, канал + шлейф) и только там, где `η_e > 0`.
  Живёт отдельно, чтобы `amr_marked_positions.py` не заводил свою копию.
- `refine_mesh` / `_bisect` (`fem.py:205`, `249`) — измельчение по правилу
  Ривары (бисекция длинного ребра, без висячих узлов), итеративное, обоим
  детям выдаются новые id; `orient_ccw` (`fem.py:184`) возвращает всем
  треугольникам положительную площадь.
- `solve_spt70_fem` (`fem.py:411`) — цикл `solve → estimate → mark → refine`
  на `amr_passes` проходов, калибровка `|B|` в опорной точке
  (`_sample_B_at`, `fem.py:375`, интерполяция, а не ближайший узел — см.
  `mesh_convergence.md` §4).
- `field_on_grid_fem` (`fem.py:472`) — итоговое `(B_r, B_z, λ)` на сетке
  разряда: интерполируется только `ψ` (оно непрерывно сквозь железо, маска не
  нужна), `λ = ψ` напрямую, а `B` берётся конечными разностями от `ψ` уже на
  сетке разряда — поэтому `div B = 0` машинно. Кэш `_FIELD_CACHE`.

**Геометрия и калибровка SPT-70** — `magnetics/spt70_system.py`:
`build_spt70_system` (`:100`, коробки железа/катушек → `μ_r`, `J_φ`),
`solve_spt70_field` (`:118`, легаси FD-путь с той же калибровкой),
`field_on_grid` (`:137`, переключатель fem/fd), `mid_channel_B` (`:166`,
`|B|(z)` по средней линии канала), `check_conformal` (`:78`, диагностика
несовпадения границ материала с линиями сетки — см. `mesh_convergence.md` §3).

## 1. Столкновения электронов

Модуль `electron_liquid/collisions.py`. Суммарная частота передачи импульса
электрона `ν_e` определяет, как часто электрон «забывает» направление и может
шагнуть поперёк поля (→ блок 2).

- `neutral_collision` (`:29`): $\nu_{en} = n_n\,k_{en}(T_e)$.
- `ionization_collision` (`:37`): $\nu_{iz} = n_n\,k_{iz}(T_e)$ — это частота,
  которую видит **электрон** (∝`n_n`); не путать с `ionization.
  ionization_probability`, где частота на **один нейтрал** (∝`n_e`).
- `coulomb_logarithm` (`:45`): $\ln\Lambda = \ln(b_{max}/b_{min})$,
  `b_max` — дебаевский радиус (16), `b_min = e/(4\pi\varepsilon_0 T_e)` —
  классическое расстояние сближения; пол `LN_LAMBDA_FLOOR = 2.0`.
- `coulomb_collision` (`:59`), формула NRL Plasma Formulary:
  $\nu_{ei} = 2.91\times10^{-12}\,n_e\,\ln\Lambda\,T_e^{-3/2}$ (`n_e` в м⁻³,
  `T_e` в эВ).
- Аномальный перенос, бомовский (по умолчанию в решателе):
  `anomaly_collision` (`:173`): $\nu_{anom} = \alpha\,\omega_{ce}$,
  `α = 1/16` — классика Бома, либо профиль `α(z)`.
- Аномальный перенос, калиброванный профиль Marks & Jorns
  (arXiv:2507.08113, Eq. 3–4):
  `anomalous_transport_profile` (`:93`):
  $$\alpha(\hat z) = \alpha_{anom}\bigl(1-\beta_{anom}\,
    e^{-((\hat z-z_{anom})/L_{anom})^2}\bigr),$$
  `anomaly_axial_shift` (`:119`) — логистический сдвиг барьера с давлением
  фона `P_B` (эффект стенда), `anomalous_alpha` (`:144`) — обе формулы вместе
  с готовыми пресетами `ANOMALY_PROFILE_PRESETS` (SPT-100, H9, GENERIC_300V).
- Альтернативная модель, Brick 2025 (AIAA SciTech 2025-0298, Eq. 8):
  `anomaly_collision_brick` (`:183`): $\nu_{anom} = c\,\nu_{ei}$ — минимум
  переноса возникает сам, там где `T_e` максимальна (`ν_{ei}∝T_e^{-3/2}`),
  вместо ручного профиля `α(z)`. Требует релаксации,
  `relax_collision` (`:210`, Eq. 16): $\nu = r\,\nu_{new} + (1-r)\,\nu_{old}$,
  `r=0.5`. Пока не подключена по умолчанию в решателе (задел).
- `electron_collision` (`:227`): $\nu_e = \nu_{en}+\nu_{iz}+\nu_{ei}+\nu_{anom}$.

## 2. Подвижность и теплопроводность поперёк поля

Модуль `electron_liquid/mobility.py`. Ничего не знает про `B` само по себе —
берёт частоты и `ω_{ce}`.

- `zeroB_mobility` (`:15`): $\mu_0 = e/(m_e\nu_e)$.
- `hall_parameter` (`:21`): $\Omega = \omega_{ce}/\nu_e$.
- `perp_mobility` (`:28`): $\mu_\perp = \mu_0/(1+\Omega^2)$ — при `Ω≫1`
  растёт с ростом `ν` (столкновения — единственный способ пересечь `B`).
- `perp_diffusion` (`:40`), соотношение Эйнштейна: $D_\perp = \mu_\perp T_e$.
- `perp_thermal_conductivity` (`:46`): $\kappa_\perp = c\,e\,n_e\,T_e\,\mu_\perp$,
  `c ≈ 2.5` (Брагинский-подобная постоянная), так что тепловой поток
  $q_e = -\kappa_\perp \nabla T_e$ [Вт/м²] наследует ту же запертость полем,
  что и ток.

## 3. λ-слои: редукция сетки

Модуль `electron_liquid/lambda_layers.py` + обёртка `solver/geometry.py`
(`LayerGeometry`). Электрон свободно бежит вдоль силовой линии и почти не
движется поперёк — значит `T_e` и «термализованный потенциал» практически
постоянны на линии (Fife 1998; Hara 2019). Диапазон λ от анодной до катодной
линии режется на `N_layers` бинов, вся 2D-сетка сворачивается в вектор длины
`N_layers`.

- `lambda_range` (`:25`): значения `(λ_anode, λ_cathode)` вдоль средней линии
  канала — граничные условия Дирихле для блоков 4 и 6.
- `thruster_body_mask` (`:51`): узлы «внутри корпуса» (upstream среза, но вне
  кольца канала) исключаются из всех слоёв.
- `build_layers` (`:65`): равномерное разбиение `[λ_lo, λ_hi]` на `N_layers`
  бинов, `idx(z,r) ∈ [0, N_layers) ∪ {-1}`; переворот индексов, если λ убывает
  анод→катод (слой 0 всегда у анода).
- `_bin` (`:101`): $\sum_{i\in\text{layer }j} w_i$ — примитив суммирования по
  слою, на нём построены все остальные.
- `layer_volume` (`:108`): $V_j = \sum dV$.
- `layer_average` (`:113`): $\langle f\rangle_j = \dfrac{\sum f\,dV}{V_j}$ —
  объёмно-взвешенное среднее (используется для `n_e`, `n_n`).
- `layer_wall_area` (`:121`): площадь стенки канала `A_j = \sum 2\pi r\,dz`,
  принадлежащая слою `j` (0 для плюмовых слоёв — они стенки не касаются).

`LayerGeometry` (`solver/geometry.py:16`) строится один раз на магнитное поле
и переиспользуется каждую Гуммель-итерацию: `average` (`:53`),
`integrate_power` (`:57`, $\int (X/\text{м}^3)\,dV \to X$),
`to_grid` (`:61`, интерполяция слой→узел по локальной λ, парная
`solve_potential.potential_on_grid`), `layer_wall_power` (`:72`).

## 4. Потенциал из непрерывности тока

Модуль `electron_liquid/layer_potential.py` + `solve_potential.py`. Электроны
пересекают силовые линии только за счёт столкновений/аномального переноса —
это и есть поперечная проводимость.

- `node_weight` (`layer_potential.py:7`) — узловой вклад в интеграл
  проводимости:
  $$w = e\,\mu_\perp n_e\,|\nabla\lambda|^2\,dV, \qquad |\nabla\lambda| = r|B|.$$
- `layer_conductance` (`layer_potential.py:26`) — сумма `w` по слою, деление
  на `dλ²` (замыкание конечной разности), грань между слоями — **гармоническое
  среднее** (правило последовательных сопротивлений):
  $$G_{j+1/2} = \frac{2\,G_j\,G_{j+1}}{G_j+G_{j+1}}.$$
- `layer_ionization_current` (`layer_potential.py:48`) — ионный ток, рождённый
  в слое: $dI_{iz,j} = e\sum_{i\in j} n_e n_n k_{iz}\,dV$.
- `solve_potential` (`solve_potential.py:6`) — баланс тока в слое
  (квазинейтральность):
  $$G_{j-1/2}(\varphi^*_{j-1}-\varphi^*_j) + G_{j+1/2}(\varphi^*_{j+1}-\varphi^*_j)
    = -dI_{iz,j},$$
  трёхдиагональная система → `utils.thomas_alg`. Анод/катод закреплены
  Дирихле, разность — напряжение разряда `V_d`.
- `potential_on_grid` (`solve_potential.py:38`) — восстановление полного 2D
  потенциала, термализованный потенциал Морозова:
  $$\varphi(z,r) = \varphi^*(\lambda) + T_e(\lambda)\,\ln\frac{n_e}{n_{ref}}.$$
- `electric_field` (`solve_potential.py:66`): $\mathbf{E} = -\nabla\varphi$
  (`np.gradient`).

**Важная развилка**, из-за которой решатель вообще устойчив: постоянен вдоль
линии только `φ*`, поэтому именно его градиент (`E_z*, E_r*`, отдельно
пересчитанный из `phi_star_grid`) идёт в омический нагрев (блок 6), а не
градиент полного `φ` — иначе больцмановская добавка `~T_e·ln(n)` возвращается
в источник нагрева и цикл расходится (подробно — `lecture.md` §10). Сборка
обоих полей — `electron_fluid._potential` (`solver/electron_fluid.py:116`).

## 5. Пристеночный слой и вторичная эмиссия

Модуль `electron_liquid/sheath_interaction.py`, всё по Goebel & Katz Ch. 7.3.
Диэлектрическая стенка заряжается до `φ_s < 0`, пока поток электронов не
сравняется с ионным; вторичная эмиссия делает `φ_s` менее отрицательным.

- `see_yield` (`:35`), Eq. 7.3-30 (максвелловски усреднённый выход):
  $$\gamma(T_e) = \Gamma(2+b)\,a\,T_e^{\,b}.$$
  Коэффициенты `a, b, Γ(2+b)` — данные материала (`structs/wall_materials.py`,
  файлы `materials/walls/*.txt`): BN (0.150, 0.549, 1.38), BNSiO2
  (0.123, 0.528, 1.36), Al₂O₃ (0.145, 0.650, 1.49), нержавейка
  (0.040, 0.610, 1.44).
- `space_charge_limited_yield` (`:50`), Eq. 7.3-42:
  $\gamma_o = 1 - 8.3\sqrt{m_e/M}$ (~0.983 для ксенона) — диагностический
  порог, сам клип наложен на потенциал, не на `γ`.
- `sheath_potential` (`:64`), Eq. 7.3-29 (классика) + предел Hobbs & Wesson
  (Eq. 7.3-41):
  $$\varphi_s = \min\Bigl(-T_e\ln\!\bigl[(1-\gamma)\sqrt{2M/(\pi m_e)}\bigr],\;
    -1.02\,T_e\Bigr).$$
  При `γ=0` — классические `≈-5.97 T_e`; предел по пространственному заряду
  `-1.02 T_e` не даёт потенциалу подняться выше при `γ→1` (и делает функцию
  определённой при «сыром» `γ>1`).
- `bohm_velocity` (`:95`), Eq. 7.3-55: $u_B = \sqrt{e T_e/M}$.
- `electron_thermal_flux` (`:104`): $\Gamma_{th} = \tfrac14 n_e\langle v_e\rangle$,
  $\langle v_e\rangle=\sqrt{8eT_e/(\pi m_e)}$ — поток ДО фильтра слоя.
- `wall_electron_flux` (`:115`), электронная часть Eq. 7.3-52:
  $\Gamma_e = \Gamma_{th}\,e^{\varphi_s/T_e}$.
- `wall_energy_loss` (`:129`), электронная часть Eq. 7.3-45/7.3-52 — главный
  канал потерь энергии электронов в диэлектрическом канале:
  $$q_e = \Gamma_e \cdot 2\,e\,T_e \;\sim\; n_e\,T_e^{3/2}\,e^{\varphi_s/T_e}.$$
- `wall_ion_energy_loss` (`:154`), ионная часть Eq. 7.3-45:
  $q_i = n_e u_B e (E_{ion}-\varphi_s)$, `E_ion = 0.58 T_e` по умолчанию
  (Eq. 7.3-46, предел по пространственному заряду; классический Бом — `0.5 T_e`).
- `wall_power_density` (`:183`): сумма `q_e + q_i` — для теплового бюджета
  стенки; в уравнение энергии электронов (блок 6) идёт только `wall_energy_loss`.

## 6. Уравнение энергии электронов

Модуль `electron_liquid/electron_energy.py`. Та же логика, что для потенциала
(блок 4), но для тепла:

$$\frac{d}{d\lambda}\!\left[G^T\frac{dT_e}{d\lambda}\right]
+ P_{ohm} - (W_{wall}+W_{ion}+W_{rad}) = 0. \tag{6.0}$$

- `ohmic_heating` (`:28`) — джоулев нагрев поперечного тока:
  $$p = \mathbf{j}_e\cdot\mathbf{E} = \sigma_\perp|E|^2
    = e\,n_e\,\mu_\perp\,(E_z^2+E_r^2) \quad [\text{Вт/м}^3].$$
  `E_z, E_r` здесь — **крестовые** (`φ*`), см. развилку в блоке 4.
- `node_thermal_weight` (`:48`) — тепловой аналог `layer_potential.node_weight`:
  $\kappa_\perp\,|\nabla\lambda|^2\,dV$, дальше та же `layer_conductance` →
  `G^T`.
- `layer_power` (`:66`): $\int p\,dV \to$ Вт на слой — используется и для
  омического источника, и для объёмных стоков (ионизация, излучение).
- `solve_electron_energy` (`:73`) — трёхдиагональная система, потери
  линеаризованы на диагональ (`loss = loss_coeff·T_e`, приём Патанкара):
  $$G^T_{j-1/2}(T_{e,j-1}-T_{e,j}) + G^T_{j+1/2}(T_{e,j+1}-T_{e,j})
    + \text{source}_j - \text{loss\_coeff}_j\,T_{e,j} = 0,$$
  `loss_coeff = (W_wall+W_ion+W_rad \text{ при предыдущем } T_e)/T_e` —
  один шаг Пикара нелинейного баланса. Анод/катод — Дирихле
  (`Te_anode`, `Te_cathode`).

## 7. Гуммель-цикл: сборка блоков 1–6

`solver/electron_fluid.py`, класс `FluidElectronSolver`. Потенциал и
температура связаны в обе стороны (проводимость `G` зависит от `T_e` через
частоты столкновений, нагрев `P_ohm` зависит от поля, то есть от потенциала) —
решаются поочерёдно, метод Гуммеля/Пикара с релаксацией.

- `_transport` (`:102`) — блоки 1+2 на текущем `T_e`: `ν → μ_⊥ → κ_⊥`.
- `_potential` (`:116`) — блок 4: `φ*, φ, E, E*`.
- `_losses` (`:141`) — блоки 5+8: `source` (омический), `loss_coeff`
  (стенка + ионизация + излучение, делённые на `T_e`).
- `_thermal_conductance` (`:168`) — блок 6, `G^T` с полом
  `thermal_floor = 1e-18` Вт/В (чтобы пустые грани не выпадали из системы).
- `solve` (`:176`) — сам цикл:
  $$T_e^{(k+1)} = (1-\text{relax})\,T_e^{(k)} + \text{relax}\cdot T_{e,\text{new}},$$
  `relax = 0.2` (без недорелаксации первая же итерация из холодного старта
  разлетается), сходимость по `max|ΔT_e| < tol = 1e-3` эВ, `max_iter = 300`.
  Дефолты: `n_layers=40`, `Te_anode=4` эВ, `Te_cathode=3` эВ, `Te_init=12` эВ,
  `kappa_coeff=35` (главная калибровочная ручка, см. `lecture.md` §14).

## 8. Глобальный баланс мощности разряда

Модуль `electron_liquid/power_balance.py`, термины Goebel & Katz Eq. 7.3-27:
$P_d = P_b + P_w + P_a + P_R + P_{ion}$. `P_w` (потери на стенку) считается
по площади в блоке 5; здесь — интегральные/токовые термины.

- `discharge_power` (`:23`): $P_d = I_d V_d$.
- `beam_power` (`:29`), Eq. 7.3-50: $P_b = \eta_b\eta_v I_d V_d$.
- `plasma_power` (`:38`), Eq. 7.3-51: $P_p = (1-\eta_b) I_d V_d$.
- `anode_power` (`:46`), Eq. 7.3-47/53: $P_a = 2\,T_{e,anode}\,I_d$.
- `anode_power_from_beam` (`:56`), Eq. 7.3-49:
  $P_a = 2\,T_{e,anode}\,I_b/\eta_b$.
- `radiated_power` (`:64`), Eq. 7.3-54:
  $P_R = n_n n_e \langle\sigma^* v_e\rangle E_{exc} V = n_n n_e k_{exc}(T_e) E_{exc}\,e\,V$.
- `ionization_power_density` (`:82`) — объёмный сток энергии электронов на
  ионизацию (+ экситация внутри эффективной цены):
  $$p_{ion} = n_e n_n k_{iz}(T_e)\,E_c(T_e)\,e \quad [\text{Вт/м}^3].$$
- `ionization_power` (`:102`), Eq. 7.3-56 — токовая альтернатива:
  $P_{ion} = (I_b + I_{iw})\,U^+$, где `U+` — потенциал ионизации, `I_b`,
  `I_iw` — токи ионов в пучок и на стенку.

## 9. Ионизация: эйлерово поле и MCC-частицы

Модуль `electron_liquid/ionization.py` — единственный источник плазмы.
Реакция `e + A → 2e + A⁺` даёт одну величину, из которой берут всё остальное:

$$S_{iz} = n_e\,n_n\,k_{iz}(T_e) \quad [\text{м}^{-3}\text{с}^{-1}]. \tag{9.0}$$

Одновременно: источник ионов/электронов (`+S_{iz}`), сток нейтралов
(`-S_{iz}`), источник тока в блоке 4 (`layer_ionization_current`), и,
умноженная на `E_c(T_e)` — сток энергии электронов (блок 8,
`ionization_power_density`).

**Эйлерово лицо** (для флюидных уравнений):

- `ionization_source` (`:38`): (9.0) как есть,
  `gas.volumetric_ionization_rate_Te`.
- `ion_continuity_source` (`:53`): $dn_i/dt|_{iz} = +S_{iz}$.
- `neutral_continuity_sink` (`:61`): $dn_n/dt|_{iz} = -S_{iz}$.
- `ionization_length` (`:69`) — диагностика: $L_{iz} = v_n/(n_e k_{iz}(T_e))$,
  средний путь нейтрала до ионизации; для нормального дизайна — порядка длины
  канала.

**MCC-частичное лицо** (для PIC тяжёлых частиц):

- `ionization_probability` (`:88`): вероятность ионизации макрочастицы за
  `dt`, $P = 1-e^{-\nu dt}$, $\nu = n_e k_{iz}(T_e)$ — частота на **один
  нейтрал** (∝`n_e`), не путать с электронной `ionization_collision`
  из блока 1 (∝`n_n`).
- `apply_ionization` (`:188`) — простой вариант: общий вес макрочастиц
  нейтрал/ион, розыгрыш Бернулли по `P`, 1:1 превращение нейтрала в ион с тем
  же импульсом и позицией. Ломается, если веса разные.
- `apply_ionization_weighted` (`:107`) — рабочая версия гибридного цикла,
  **разные веса** ионов и нейтралов (`n_n` на два порядка выше `n_i`, общий вес
  не может обслужить оба — см. `hybrid.md` §3). Нейтрал веса `w` рождает
  $$N \sim \mathrm{Poisson}\!\left(\frac{w\,\nu\,dt}{W_i}\right), \qquad
    \nu = n_e k_{iz}(T_e),$$
  ионов веса `W_i` (=`ion_weight`), теряя `N·W_i` из своего веса.
  Математическое ожидание переданного веса `= w·ν·dt` — точная физическая
  скорость при любом соотношении весов; Пуассон, а не Бернулли, потому что при
  типичном соотношении ~50 ожидание на макрочастицу уже не мало. Нейтрал,
  стёршийся ниже `W_i`, разыгрывается русской рулеткой — становится
  полновесным ионом с вероятностью `w/W_i`, иначе удаляется (не смещает
  баланс, не даёт копиться «бессмертной» мелочи).

## 10. Нейтралы: инжекция, пролёт, стенки

- `injection/inject.py:inject_on_grid` (`:7`) — инжекция с анода: число
  макрочастиц $N = \lfloor \dot m\,dt/(m\,w)\rfloor$ + случайное округление
  остатка (несмещённый инжектор, отсюда «блуждание» реального расхода вокруг
  `mdot` в проверках баланса массы). Скорость — полумаксвелловское
  распределение (поток через плоскость): нормальная компонента из
  `v_z = v_{th}\sqrt{-2\ln(1-u)}` (Rayleigh-поток), тангенциальные —
  Бокс-Мюллер `v_th * Gauss`. Рождение «размазывается» по шагу: каждая
  частица летит случайную долю `dt` перед стартом счёта.
- `neutrals/neutrals.py:free_flight` (`:24`) — баллистический пролёт в 3D +
  поворот назад в плоскость `(r,z)`: `x = r+v_r τ`, `y = v_θ τ`,
  `r_{new}=\sqrt{x^2+y^2}`, скорости пересчитываются поворотом на угол между
  старым и новым азимутом (общий примитив, используется и нейтралами, и
  ионами — `ions.push_ions`).
- `sample_wall_flux` (`:57`) — диффузное переизлучение при температуре стенки:
  нормальная компонента из потокового максвеллиана
  `v_n = v_{th}\sqrt{-2\ln(1-u)}`, тангенциальные — гауссовы, `v_th` от
  `WorkingSubstance.thermal_speed`.
- `apply_boundaries` (`:69`) — пять веток границ (открытый плюм; анод;
  внутренняя/внешняя стенка канала; передняя грань корпуса), каждая —
  переизлучение по `sample_wall_flux`; `z_prev` решает, была ли частица в
  канале или в плюме (тот же приём в `ions.apply_ion_boundaries`).
- `node_volume` (`:5`) — объём кольцевой ячейки узла (не куб, кольцо):
  $dV = \pi(r_{outer}^2-r_{inner}^2)\,dz$, торцевые узлы — половинный вес.

## 11. Депонирование частиц на сетку

`deposition/deposit.py` — билинейная CIC-схема (общая для нейтралов, ионов,
депонирования плотности).

- `locate_particle` (`:6`): дробные индексы ячейки `(i_z, i_r)` +
  веса `(w_z, w_r) ∈ [0,1)`.
- `scatter` (`:26`): вес частицы `w·q` раскладывается по 4 узлам ячейки
  билинейно, суммируется `np.bincount`.
- `gather` (`:49`): обратная операция — билинейная интерполяция сеточного поля
  в позицию частицы:
  $$f_p = \sum_{4\text{ узла}} f_{node}\,(1-\Delta z)^{\pm}(1-\Delta r)^{\pm}.$$

`ions/moments.py` строит на этом физические моменты:

- `number_density` (`:26`): $n = \dfrac{\text{scatter}(w)}{dV}$.
- `mean_velocity` (`:43`) — первый момент скорости,
  $\bar v = \dfrac{\text{scatter}(w v)}{\text{scatter}(w)}$, с двойным
  биномиальным сглаживанием (`smooth`, `:72`, ядро `[1 2 1]/4`,
  отражающий край) — среднее, а не скорость пучка (там, где ионы летят в обе
  стороны, среднее гасится; для скорости выхода — `beam.BeamTally`, блок 13).
- `seed_uniform` (`:91`) / `seed_plasma_profile` (`:131`) — начальная засевка
  (не решение, а стартовая точка): равномерно по объёму / по реалистичному
  осевому профилю, максвелловские скорости.

## 12. Ионы: пуш, границы, CFL

Модуль `ions/ions.py`. Ионы — кинетические макрочастицы (как нейтралы), но
чувствуют поле, которое строит электронная жидкость. Магнитная сила и
столкновения ионов сознательно не учтены (ларморовский радиус Xe⁺ при 150 Гс,
20 км/с ~20 см, много больше канала).

- `push_ions` (`:40`) — kick-drift (Эйлер-Кромера), первый порядок по `dt`:
  $$v_z \mathrel{+}= \frac{e}{m}E_z(z_{old})\,dt, \qquad
    v_r \mathrel{+}= \frac{e}{m}E_r(z_{old})\,dt,$$
  затем `free_flight` (блок 10) — дрейф и поворот в плоскость. Поля `E_z, E_r`
  собираются билинейно (`gather`) в старой позиции частицы.
- `apply_ion_boundaries` (`:92`) — пять веток, как у нейтралов, но с другим
  исходом: анод/стенки/передняя грань — рекомбинация (ион возвращается атомом
  через `_born_neutrals`, `:71`, та же `sample_wall_flux`); открытая граница
  плюма — **это и есть пучок**, частицы отдаются целиком (не суммой), потому
  что распределение по скоростям и углам больше взять неоткуда (см. блок 13).
- `cfl_dt` (`:178`) — предельный ионный шаг по Куранту:
  $$v_{max} = \sqrt{\frac{2 e V_d}{m}}, \qquad
    dt = \text{courant}\cdot\frac{\min(dz,dr)}{v_{max}}, \quad
    \text{courant}=0.4.$$
  Для SPT-70 (Xe, 300 В, 0.5 мм) даёт `dt ≈ 1e-8` с — единственное жёсткое
  ограничение шага в модели (в отличие от полного PIC, где доминировала бы
  электронная плазменная частота — именно на этом гибридная схема и
  экономит).

## 13. Диагностика пучка: тяга, Isp, расходимость

Модуль `ions/beam.py`, класс `BeamTally`. Всё, по чему судят о холловском
двигателе — момент частиц, пересекающих границу плюма; поэтому это
накапливается, а не читается мгновенно (за один макрошаг границу пересекают
сотни макрочастиц — ~5% шума в лучшем случае, за дыхательный цикл гуляет ещё
сильнее). Копится с момента `reset_beam()` (после схода стартового
переходного процесса) и делится на прошедшее время в `report`.

- `add_ions` (`:61`) — накопление на каждый вызов: `weight += Σw`,
  `p_z += Σw v_z`, `p_r += Σw|v_r|`, `energy += Σw·v²/2`,
  `speed_weighted += Σw|v|`, `cos_weighted += Σw|v|\cosθ`,
  `θ = \operatorname{atan2}(|v_r|, v_z)` — плюс гистограммы `|v|` и `θ`.
- `add_neutrals` (`:79`) — не-ионизованные атомы, уходящие через плюм: несут
  мало импульса каждый, но весь расход, не пошедший в ионизацию — важны для
  Isp сильнее, чем для тяги.
- `report` (`:90`) — производные величины за окно `elapsed`:

$$T = T_{ion}+T_{neutral}, \qquad
  T_{ion}=\frac{m\sum w v_z}{\Delta t}\Big|_{ions}, \qquad
  T_{neutral}=\frac{m\sum w v_z}{\Delta t}\Big|_{neutrals}. \tag{13.1}$$

$$Isp = \frac{T}{\dot m\,g_0}, \qquad \dot m = \text{расход через анод}
  \;\Rightarrow\; \text{неионизованный атом честно тянет } Isp \text{ вниз.}
  \tag{13.2}$$

$$V_{beam} = \frac{m\langle v^2\rangle}{2e}
  \; \text{(средняя кинетическая энергия иона в вольтах)}, \qquad
  \eta_v = V_{beam}/V_d. \tag{13.3}$$

$$\theta_{mean} = \frac{\sum \theta\, w_\theta}{\sum w_\theta}\ \text{(по гистограмме)},
  \quad \langle\cos\theta\rangle = \frac{\sum w|v|\cos\theta}{\sum w|v|}
  \ \text{(КПД расходимости)}. \tag{13.4}$$

  Плюс `θ_95` — полуугол конуса, содержащего 95% пучка (интерполяция
  кумулятивной гистограммы), `I_{beam} = e\cdot\text{weight}/\Delta t`
  (реальный ионный ток через границу плюма), `mass_utilization =
  \dot m_{beam}/\dot m`.
- Что **не** входит в `T`: давление на анод и переднюю грань, импульс
  инжектируемого пропеллента до ускорения — малы для холловского двигателя
  (пучок доминирует на порядок), но не нулевые; `T` здесь — тяга пучка, не
  тяга по балансу сил.

## 14. Гибридный цикл: два шага по времени, токи, баланс массы

`solver/hybrid.py`, класс `HybridSolver` — точка, где всё выше замыкается в
петлю: электроны (флюид) дают `E, T_e`, ионы и нейтралы (частицы) дают
`n_e=n_i, n_n`, оператор ионизации (блок 9) их связывает.

**Два шага по времени.** Мелкий `dt` (блок 12, `cfl_dt`) — только для пуша
ионов; всё остальное (инжекция, пуш нейтралов, ионизация, электронный
Гуммель-solve) — на `dt_slow = n_sub · dt`, `n_sub = 50` по умолчанию.
`_ion_substep` (`:146`) повторяется `n_sub` раз внутри `_heavy_step` (`:167`) +
`_electron_update` (`:194`) — всё вместе один `macro_step` (`:202`).

**Токи** (`macro_step`, `:216`) — вес частиц это реальные атомы/ионы, поэтому
`weight·e/dt` — амперы:

$$I_{beam} = \frac{e\cdot\text{tally[beam]}}{dt_{slow}}, \qquad
  I_{anode} = \frac{e\cdot\text{tally[anode]}}{dt_{slow}}, \qquad
  I_{wall} = \frac{e\,(\text{tally[inner]}+\text{tally[outer]}+\text{tally[front]})}{dt_{slow}},$$

$$I_{iz} = \frac{e\cdot n_{events}\cdot W_i}{dt_{slow}}, \qquad
  n_{events} = \texttt{apply\_ionization\_weighted(...)} \text{ (блок 9)}.$$

`I_beam` считается по частицам, реально пересёкшим границу плюма **за все
`n_sub` ионных подшагов** этого макрошага (сумма `tally['beam']` по
подшагам); `I_iz` — по числу новых ионных макрочастиц, рождённых **один раз**
в `_heavy_step` на весь макрошаг. Оба — токи, но разного происхождения: один
меряет рождение ионов в зоне ионизации, другой — их гибель через срез. В
стационаре они обязаны совпадать (с поправкой на потери на стенки/анод); пока
разряд не устоялся (см. `hybrid.md` §5), не совпадают — см. обсуждение в
сообщении к этому файлу.

- `reset_beam` (`:248`) — открывает окно накопления `BeamTally` (блок 13) с
  текущего момента, чтобы не мерить тягу по вымывающейся засевке.
- `performance` (`:255`) — `self.beam.report(...)` за прошедшее окно.
- `mass_balance` (`:261`) — проверка сохранения пропеллента:
  $$\text{injected} = \frac{\dot m}{m}\,t, \qquad
    \text{residual} = \text{in\_domain}+\text{escaped}-\text{injected}-\text{seeded},$$
  `escaped = tally[beam] + tally[neutral_escape]` — сток у плюма имеет ДВА
  канала (ионы-пучок и неионизованные атомы), оба обязаны считаться, иначе
  баланс «утекает» на десятки процентов, не будучи физической утечкой (ловушка,
  задокументированная в `hybrid.md` §4).

## 15. Модель рабочего тела: константы скоростей реакций

`structs/classes.py`, класс `WorkingSubstance` — хранилище таблично заданных
констант скорости как функций `T_e` (максвелловское ФРЭЭ) или `E/N`
(свормовые таблицы). Данные — из HallThruster.jl (`materials/reactions/`,
формат разбирает `utils.load_hallthruster_table`, `utils.py:99`, линейная, не
кубическая интерполяция — вблизи порога кубик уходит в минус) или LXCat
(`utils.load_xy_table`, `utils.py:77`, кубическая интерполяция с клэмпом за
краями таблицы).

- `thermal_speed` (`:78`): $v_{th}=\sqrt{k_B T/m}$ (T в К).
- `mean_speed` (`:82`): $\bar v = \sqrt{8k_BT/(\pi m)}$.
- `volumetric_ionization_rate` (`:116`), путь по `E/N`:
  $S_{iz}=n_e N k_{iz}(E/N)$.
- `volumetric_ionization_rate_Te` (`:120`), путь по `T_e` (тот, что
  использует `ionization.ionization_source`): $S_{iz}=n_e N k_{iz}(T_e)$.
- `ionization_energy_cost` (`:151`) — эффективная цена ионизации `E_c(T_e)`:
  прямая колонка таблицы, если есть, иначе собирается из порогов
  HallThruster.jl:
  $$E_c(T_e) = E_{iz} + E_{exc}\cdot\frac{k_{exc}(T_e)}{k_{iz}(T_e)}$$
  (среднее число возбуждений на одну ионизацию × энергия одного
  возбуждения; `k_iz` подпёрт снизу, чтобы отношение не взрывалось при малых
  `T_e` — произведение `E_c·k_iz` при этом остаётся конечным и правильным:
  `E_iz·k_iz + E_exc·k_exc`).
- Готовые фабрики — `structs/propellants.py`: `xenon()`, `krypton()` (полный
  набор реакций), `argon()` (только ионизация — без `elastic_Ar` не может
  питать электронную жидкость, `nu_en` не из чего считать), `nitrogen()` (без
  таблицы возбуждения, `E_c` = чистый порог ионизации).

## 16. Базовые плазменные параметры

`electron_liquid/default_plasm_params.py`.

- `omega_ce` (`:9`): $\omega_{ce} = |e|B/m_e$.
- `debye_radius` (`:14`): $\lambda_D = \sqrt{\varepsilon_0 T_e/(n_e e)}$
  (`T_e` в эВ — форма без `k_B/e`, потому что `k_BT = eT_e` при `T_e` в
  вольтах).

## 17. Литература

- Goebel D.M., Katz I. *Fundamentals of Electric Propulsion*, Wiley/JPL 2008,
  Ch. 3, 7 (особенно 7.3) — слой, ВЭЭ, баланс мощности разряда; источник
  бо́льшей части формул блоков 5 и 8.
- Fife J.M. *Hybrid-PIC modeling and electrostatic probe survey of Hall
  thrusters*, PhD thesis, MIT, 1998 — квази-1D модель по силовым линиям
  (λ-слои), архитектура hybrid-PIC, подциклирование по времени.
- Hara K. *An overview of discharge plasma modeling for Hall effect
  thrusters*, PSST 28 (2019) — обзор, устойчивость гибридных схем,
  приэлектродный горб потенциала.
- Boeuf J.P., Garrigues L. *Low frequency oscillations in a stationary
  plasma thruster*, JAP 84 (1998) — дыхательная мода в 1D гибридной модели.
- Birdsall C.K., Langdon A.B. *Plasma Physics via Computer Simulation* —
  веса макрочастиц, цифровая фильтрация плотности (`ions/moments.smooth`),
  русская рулетка при обрезании весов.
- Zienkiewicz O.C., Taylor R.L. *The Finite Element Method*, Vol. 1 — слабая
  форма, P1-элементы, сборка (блок 0, FEM-путь).
- Zienkiewicz O.C., Zhu J.Z. *A simple error estimator and adaptive
  procedure for practical engineering analysis*, IJNME 24 (1987) —
  ZZ-оценка ошибки, на которой построен маркер AMR.
- Rivara M.-C. *Mesh refinement processes based on the generalized
  bisection of simplices*, SIAM J. Numer. Anal. 21 (1984) — бисекция по
  длинному ребру, `fem.refine_mesh`.
- Hobbs G.D., Wesson J.A. *Heat flow through a Langmuir sheath in the
  presence of electron emission*, Plasma Physics 9 (1967) — предел
  сеточного потенциала по пространственному заряду (`PHI_SPACE_CHARGE`).
- Marks T., Jorns B. *Uncertainty quantification of a multi-component Hall
  thruster model at varying facility pressures*, arXiv:2507.08113 (2025) —
  калиброванный аномальный перенос (`anomalous_transport_profile`,
  `anomaly_axial_shift`), пресеты по двигателям.
- Brick D., Roberts C., Jorns B. *Numerical Investigation of Electron
  Energy Transport in Hall Thrusters*, AIAA SciTech 2025-0298 —
  `ν_anom = c·ν_ei` (`anomaly_collision_brick`, `relax_collision`).
- NRL Plasma Formulary — формула `ν_ei = 2.91e-12 n_e lnΛ T_e^{-3/2}`.
- LXCat (lxcat.net) — источник формата свормовых таблиц (`load_xy_table`).
- HallThruster.jl (github.com/UM-PEPL/HallThruster.jl) — источник и формат
  таблиц реакций/порогов (`load_hallthruster_table`,
  `materials/reactions/`).
