# hetsim

Гибридная осесимметричная модель холловского двигателя (СПД-70): тяжёлые
частицы кинетически, электроны — как замагниченная жидкость на слоях вдоль
силовых линий.

```
   электроны (флюид)  --E, Te-->  ионы и нейтралы (частицы)
        ^                                    |
        +--------- n_e = n_i, n_n ------------+
```

## Запуск

```bash
python -m src.examples.spt70
```

Считает связанный прогон и складывает всё в папку `out/`: карты полей, графики
токов, профили по каналу, распределения пучка, `performance.txt` с тягой и
КПД, `setup.txt` с конфигурацией и `history.csv`. Аргументы — число макрошагов
и имя папки:

```bash
python -m src.examples.spt70 1500 run_a
```

**Про длительность.** Время пролёта нейтрала по каналу — около 125 мкс, и
быстрее этого в разряде не устанавливается ничего. 300 макрошагов это 140 мкс,
то есть меньше двух заправок канала: чистый пусковой переходник. Дышащая мода
становится видна от ~700 макрошагов. `performance.txt` сам предупреждает, когда
прогон слишком короткий, чтобы цитировать из него числа.

## Структура

| | |
|---|---|
| `src/config.py` | эталонный разряд СПД-70: тяга, геометрия, сетка |
| `src/magnetics/` | магнитостатика: узловой P1 FEM с AMR (`fem.py`), геометрия магнитной системы (`spt70_system.py`), старый конечно-разностный путь (`magnetic.py`) |
| `src/neutrals/`, `src/injection/` | нейтралы: инжекция с анода, пролёт, стенки |
| `src/ions/` | ионы: пуш полем, границы, моменты, диагностика пучка |
| `src/deposition/` | депонирование частиц на сетку и обратная интерполяция |
| `src/electron_liquid/` | блоки 1–6 электронной жидкости плюс ионизация |
| `src/solver/` | сборка: `PlasmaState`, электронный солвер, гибридный цикл |
| `src/viz/` | карты 2D-полей |
| `src/structs/` | классы, рабочие тела, материалы стенок |
| `materials/` | таблицы сечений и SEE-выходов (LXCat / HallThruster.jl) |
| `legacy/` | поблочные проверочные скрипты, см. [`legacy/README.md`](legacy/README.md) |

## Оговорка

Геометрия магнитной системы — иллюстративное приближение двигателя класса
СПД-70: топология и масштаб правдоподобны, но это не данные производителя.
