# legacy/

Проверочные скрипты, каждый из которых отвечает на один вопрос про один блок.
Они не устарели по содержанию — они устарели по роли: раньше это и были
«примеры», а теперь полный расчёт живёт в одном месте,
`python -m src.examples.spt70`.

Всё здесь **запускается**: импорты переписаны на новую структуру
(`src.config`, `src.viz`), запуск — `python -m legacy.<имя>` из корня репозитория.
Если что-то тут перестанет работать после правки в `src/` — это сигнал, что
правка сломала блок, а не что скрипт можно выбросить.

## Магнитостатика

| скрипт | вопрос |
|---|---|
| `magnetic_field.py` | как выглядит поле: карта \|B\| с линиями и профиль `B_r(z)` |
| `fem_check.py` | FEM против старого конечно-разностного пути (`method="fd"`) |
| `mesh_convergence.py` | сколько нужно `amr_passes` и какие метрики вообще имеют право сходиться |
| `amr_marked_positions.py` | куда AMR кладёт свои 5% элементов за проход |

Разбор — в [`../docs/mesh_convergence.md`](../docs/mesh_convergence.md) и
[`../docs/lecture.md`](../docs/lecture.md).

## Электронная жидкость, поблочно

| скрипт | блок |
|---|---|
| `collisions_check.py` | 1 — частоты столкновений, в двух опорных точках |
| `mobility_check.py` | 2 — подвижность и диффузия там же |
| `hall_parameter.py` | 1→2 на реальном поле СПД-70 |
| `anomalous_transport.py` | аномальный перенос, калиброванная модель Marks, Eckels, Mora & Gorodetsky |
| `lambda_layers_check.py` | 3 — сведение сетки `(z, r)` к слоям вдоль линий поля |
| `conductance_check.py` | 4a — поперечные проводимости слоёв `G_{j+1/2}` |
| `potential_check.py` | 4 — термализованный потенциал `φ*(λ)` |

## Прогоны на заданных плотностях

Всё ниже считает `PlasmaState.placeholder` — `n_e` и `n_n` заданы профилями, а
не получены из частиц. Читать можно только форму, не величины. В гибридном
прогоне этого больше нет.

| скрипт | что показывает |
|---|---|
| `solve_spt70.py` | самосогласованный электронный расчёт, `Te`/`φ`/`E_z` по каналу |
| `power_budget.py` | куда уходит энергия электронов |
| `voltage_sweep.py` | как пик `Te` масштабируется с разрядным напряжением |
| `field_maps.py` | карты всех 2D-полей (рисование переехало в `src/viz/`) |

## Нейтралы и гибрид

| скрипт | что показывает |
|---|---|
| `neutral_flow.py` | чистый поток нейтралов: расход через сечения, баланс массы |
| `hybrid_run.py` | короткая версия связанного прогона с графиком в один файл |

`hybrid_run.py` — предшественник `src/examples/spt70.py`: та же физика, но
печатает в терминал и рисует одну картинку вместо папки с отчётом.
